# Задание: журналы документов, как в 1С

Для рабочего чата «админка». Решение владельца 2026-10-26: делать **сейчас**, впереди тарифов из базы и правил «если → то». **Начать с журнала «Задачи».**

## Зачем
Таблицы документов в базе есть (`docs/product/документооборот.md`, раздел 4), а экранов для них нет — владелец не видит, что лежит в базе. Задачи уже создаются загрузкой из Excel.

## Что такое журнал
- Список документов: номер, дата, клиент, статус и главные поля документа; поиск, отборы, сортировка — как в остальных списках админки (компактный вид, настройка колонок, избранное).
- Строка открывает **карточку документа** только для просмотра: все поля, автор, даты, и **связанные документы** (уже есть страница `app/(admin)/related/[doc]`) — заказы, посылка, сборка/упаковка/взвешивание и т.д.
- **Только просмотр.** Создание и правка — через АРМы (позже).
- Удалённые (`deletedAt`) — скрыты, отбор «Показать удалённые».

## Шаг 1 — «Задачи» (`ParcelTask`)
- Раздел «Склад», пункт «Задачи».
- Колонки: номер, дата создания, клиент (код + ФИО), страна, статус (`ParcelTaskStatus`), количество заказов, посылка (номер `PS-…`, ссылка), примечание, автор.
- Отборы: статус, клиент, страна, период.
- Карточка: поля задачи, внутренний комментарий (только сотрудникам), заказы задачи (ссылки), посылка, сборка / упаковка / взвешивание, если есть.
- Учесть решение раздела 13 `будущее.md`: номер задачи станет «по порядку», а нынешний номер — «Кодом отправки». Сейчас показывать нынешний номер; колонку «Код отправки» добавить, когда дойдёт эта переделка.

## Дальше — по одному журналу за PR
1. Склад: Сортировка, Приём, Раскладка, Сборка, Упаковка, Взвешивание.
2. Логистика: Коробы, Реестры отправки, AWB.
3. Финансы: Заявки на пополнение, Приход ДС, Распределение оплат, Изменение долга клиента, Счета агентов, Выплаты агентам.
4. Справочники: Ячейки хранения, Агенты; Потеряшки.

Меню: группы «Документы / Справочники / Регистры» внутри разделов — по разделу 9 `будущее.md`.
