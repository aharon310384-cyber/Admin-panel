## 1. Тестовая копия админки (staging)
Владелец: «Да, супер. Запомни. Позже будем делать» (2026-10-17). Начать после того, как наведём общий порядок.

Зачем: видеть изменения до выкладки в прод. Порядок работы после запуска: изменение → выкладка на тест → владелец смотрит по ссылке → слияние PR → выкладка в прод.

Как задумано:
- адрес `test.cabinet.postmanfox.com` — поддомен, A-запись на сервер. **Шаг владельца:** один раз добавить запись в DNS домена;
- тот же сервер: `/opt/postmanfox-staging`, отдельный процесс PM2 `postmanfox-staging` на своём порту, отдельная база PostgreSQL `postmanfox_staging`;
- данные — копия боевой базы, обновляется по команде. Данные настоящие, поэтому вход на тест по отдельному паролю (basic auth в nginx) плюс HTTPS;
- уведомления в Telegram на тесте выключены (без `TELEGRAM_BOT_TOKEN`), чтобы клиенты не получали сообщений с теста;
- управление — кнопкой «Сервер»: новые команды «выложить ветку на тест» и «обновить копию базы на тесте»;
- ресурсы: ещё ~200–300 МБ памяти (свободно ~1,4 ГБ).

## 2. Настройки интерфейса по образцу 1С
В «Настройках» добавлены пункты «Настройка панелей…», «Настройка начальной страницы…», «Настройка панели разделов…» (PR #8, помечены «скоро»). Что будет в каждом окне — обсуждаем.

Черновик предложения (не утверждён):
- **Панель разделов:** «Доступные / Выбранные разделы», порядок, вид (картинка, текст). Разделы: Клиенты (клиенты, получатели, заказы), Склад (АРМы, посылки, наименования), Логистика (виды доставки, страны, тарифы; позже коробы, реестры, AWB), Финансы (курс, расчёт и оплата; позже приход ДС, распределение, долг, агенты), Справочники (статусы, услуги; позже агенты, ячейки), Администрирование (настройки; позже пользователи).
- **Панели:** панель разделов, функций текущего раздела, открытых, избранного, истории. Каждую можно поставить сверху, слева, справа, снизу или убрать. «Стандартные» — разделы сверху, открытые снизу.
- **Начальная страница:** формы в левой и правой колонке (АРМ приём заказа, показатели, график, последние посылки, топ заказов).
- Настройки — свои у каждого сотрудника.
- Меню «Данные» — оставить как «Все функции» или убрать — не решено.
