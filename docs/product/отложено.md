## 1. Тестовая копия админки (staging)
Владелец: «Да, супер. Запомни. Позже будем делать» (2026-10-17). Начать после того, как наведём общий порядок.

Зачем: видеть изменения до выкладки в прод. Порядок работы после запуска: изменение → выкладка на тест → владелец смотрит по ссылке → слияние PR → выкладка в прод.

Как задумано:
- адрес `test.cabinet.postmanfox.com` — поддомен, A-запись на сервер. **Шаг владельца:** один раз добавить запись в DNS домена;
- тот же сервер: `/opt/postmanfox-staging`, отдельный процесс PM2 `postmanfox-staging` на своём порту, отдельная база PostgreSQL `postmanfox_staging`;
- данные — копия боевой базы, обновляется по команде. Данные настоящие, поэтому вход на тест по отдельному паролю (basic auth в nginx) плюс HTTPS;
- уведомления в Telegram на тесте выключены (без `TELEGRAM_BOT_TOKEN`), чтобы клиенты не получали сообщений с теста;
- управление — кнопкой «Сервер»: новые команды «выложить ветку на тест» и «обновить копию базы на тесте»;
- ресурсы: ещё ~200–300 МБ памяти (свободно ~1,4 ГБ).

## 5. Отслеживание посылок
Владелец (2026-10-18): статус «Доставлена» вручную не поменять — нужно, чтобы система следила сама; плюс ручной вариант на крайний случай. Около 50 посылок в месяц, номера и международных перевозчиков, и агентов (Meest China), бюджет до $120 в год. Выбран 17TRACK: бесплатно 100 номеров в месяц (дальше $119 в год за 5000); Meest China подключена к 17TRACK.
- **Сделано (2026-10-18):**
  - посылка «Отправлена» с трек-номером ставится на слежение в 17TRACK (сразу при отправке или смене трека, а по расписанию — отправленные за последние 60 дней; более старые — кнопкой в карточке);
  - проверка раз в 2 часа (cron на сервере → `/api/tracking/sync`), кнопка «Проверить посылки сейчас» в настройках, «Обновить отслеживание» в карточке;
  - «Доставлена» в 17TRACK — посылка становится «Доставлена» сама: история статусов (автор пустой, примечание «17TRACK: …»), версия «Статус «Доставлена» — по данным 17TRACK», сообщение клиенту в Telegram;
  - возврат, «не удалось вручить», запрос таможни, «давно нет новостей», 14 дней без данных, номер не принят — отметка «требует внимания»: красным в списке, кнопка-отбор «Требуют внимания (N)», метка в карточке. Статус меняет человек;
  - в карточке: статус 17TRACK, перевозчик, последнее событие, все события; в списке — колонка «Отслеживание»;
  - ручные инструменты: отметить посылки в списке → «Поставить статус»; «Статус по трек-номерам» — вставить список номеров, найти посылки, поставить статус;
  - ключ API 17TRACK вводит администратор в «Настройки» → «Отслеживание посылок» (проверяется сразу, в браузер не отдаётся — только последние 4 знака; хранится в базе — `TrackingSettings`).
  - Код: `lib/track17.ts` (API), `lib/tracking.ts` (правила), `lib/tracking-labels.ts`, `actions/tracking.ts`, `app/api/tracking/sync`, `components/parcels/` (`tracking-block`, `parcels-table`, `status-by-tracks`), `components/settings/tracking-settings.tsx`, таблица `ParcelTracking`, `scripts/deploy/tracking-cron.sh`.
- **Шаг владельца:** зарегистрироваться на api.17track.net и вставить ключ в настройки.
- **Запасной перевозчик, язык, данные получателя (2026-10-20, решения владельца):**
  - Язык событий — настройка («Настройки» → «Отслеживание» → «Язык событий», по умолчанию русский): 17TRACK отдаёт события на нём бесплатно, если язык даёт сам перевозчик; иначе — на языке перевозчика. Платный перевод 17TRACK (1 номер квоты за язык) не включаем. Дальше, когда кабинет станет многоязычным, — перевод событий своим ИИ с запоминанием.
  - Запасной перевозчик: номера с приставками из настройки (владелец: CK, LK, LC — окончание не важно) сначала ищутся как обычно; 17TRACK не определил перевозчика — номер сразу ставится на запасного; за N часов (24) ничего не нашёл (NotFound) — переставляется на запасного (`/changecarrier`, один раз, `ParcelTracking.fallbackAt`; 17TRACK спишет ещё 1 номер). Перевозчик выбирается поиском по списку 17TRACK (владелец: Meest Group — CK…MG на 17TRACK находится как Meest Group).
  - Данные получателя (страна, индекс, 4 последние цифры телефона, дата отправки) передаются 17TRACK только если перевозчик их просит (ошибки -18010018/19/20/22 при постановке) — второй заход с ними.
  - Квота 17TRACK (с 07.01.2026): новым аккаунтам — 200 номеров один раз, ежемесячного пополнения нет.
