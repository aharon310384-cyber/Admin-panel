# Задание: тариф и вид доставки при загрузке из Excel

Для рабочего чата «админка». Решения владельца 2026-10-29. Связано: `задание-excel.md` (правила 3–4), `будущее.md`, раздел 11.

## Что уже есть
Тарифы — только в базе («Логистика → Тарифы»), у тарифа страны (`countryCodes`) и вид доставки. `findShippingTariff(страна, вид)` уже работает при оформлении посылки и в карточке посылки; массовый ввод подставляет вид доставки по стране.

## Чего нет — сделать
В загрузке строки Excel (`actions/excel-row.ts`) вид доставки не ставится, тариф не подбирается, цена файла не сверяется.

### 1. Вид доставки — из столбца C (`LR`, тарифный план строки)
Правило владельца:
| Столбец C | Вид доставки |
|---|---|
| `RU` | авто (TRUCK) |
| `UA` | авиа (AIR) |
| `SEA` | море (SEA) |
| `PL` и все остальные (`EU`, `US`, `TL`, `AU`, `KR`, `RO`, `M01`, `UZ` …) | авиа (AIR) |
- Соответствие «код → вид доставки» хранится в настройках загрузки Excel (`ExcelImportSettings`), правится в админке; «по умолчанию» — авиа. Не в коде (принцип «система на продажу»).
- Пустой столбец C — ⚠ и выбор вида доставки вручную в окне проверки.
- Вид доставки записывается в заказы и посылку (`deliveryType`).

### 2. Тариф — по стране получателя + виду доставки
- Страна — из адреса получателя (как сейчас), вид — из п. 1 → `findShippingTariff`.
- Пример: получатель в России, столбец C `RU` → «Россия (авто)» 15 + 5; столбец C `PL` → авиа-группа «ОАЭ, Америка, Канада, Россия и др.» 20 + 25.
- Нет тарифа для страны и вида — ⚠ «нет тарифа», цена — из файла (так будет, например, пока тариф не заведён).

### 3. Сверка цены (правило 4 `задание-excel.md`)
- Цена по тарифу = вес × $/кг + оформление (вес — из строки; расчётный вес — как в `parcel-calc`).
- Совпадает с ценой файла — ✓. Не совпадает — ⚠ «в файле X $, по тарифу Y $», по умолчанию берётся цена системы, владелец может выбрать цену файла в окне проверки.

### 4. Тарифы в базе
- **Добавить тариф «Узбекистан (авиа)»: UZ, AIR, 15 $/кг + 2 $** — в начальные данные (`prisma/upgrade-tariffs.ts`, повторный запуск ничего не дублирует).
- Таиланд остаётся в группе «Юго-Восточная Азия, Австралия» 13 + 20 — владелец исправил формулу в Excel, теперь совпадает.
