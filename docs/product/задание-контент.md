# Задание: контент из базы — черновики постов (шаг 1)

Для отдельного рабочего чата «контент». Решения владельца — `docs/product/будущее.md`, раздел 5. Делается параллельно с выкупом (владелец, 2026-11-03).

Перед началом прочитать: `AGENTS.md` (правило 6 — система на продажу), `docs/product/будущее.md` разделы 0 и 5.

## Зачем
Владелец один, на соцсети времени нет. В базе лежат настоящие факты о работе склада. Программа сама превращает их в готовые посты, владелец только проверяет и публикует.

## Шаг 1 — только черновики
Программа готовит пост (текст + картинка-карточка). Владелец копирует и публикует сам. Подключения к соцсетям в этом шаге **нет**.

## Три вида постов
1. **Итоги недели.** Сколько посылок отправлено за неделю и в сколько стран, топ стран. Источник: посылки и история их статусов (дата отправки), страна получателя.
2. **Реальные сроки доставки.** Средний срок от отправки до вручения по странам (и по виду доставки) за последние N дней. Источник: история статусов посылки + отслеживание 17TRACK (`ParcelTracking`, статус `Delivered`).
3. **Тарифы и акции.** Изменился тариф в справочнике (`ShippingTariff`) — готовится пост «Новая цена…». Плюс кнопка «Пост о тарифе» вручную.

## Что сделать
### Таблица «Черновик поста»
- `companyId` — чья компания (правило 6).
- Вид (итоги недели / сроки / тариф), период или повод, текст, картинка, данные, из которых посчитано (чтобы можно было проверить), статус: черновик → опубликован (отметка вручную) / отклонён. Автор, даты.

### Как появляются черновики
- Итоги недели — автоматически раз в неделю (день и час в настройках).
- Сроки — раз в месяц (настройка) и кнопкой «Собрать сейчас».
- Тариф — при изменении тарифа и кнопкой.
- Новый черновик — оповещение владельцу (`notifyOwner`).

### Картинка-карточка
- Квадрат 1080×1080 (подходит для Instagram и Facebook): логотип, цвета и название компании — **из карточки компании, не из кода**; крупные цифры, подпись.
- Кнопка «Скачать картинку» и «Скопировать текст».

### Тексты
- Шаблоны текстов — в настройках (владелец правит без программиста), с подстановками: `{посылок}`, `{стран}`, `{страна}`, `{дней}`, `{цена}` и т.п.
- Язык постов — в настройках (на старте русский).

### Экран в админке
- Раздел (предложение: «Маркетинг» → «Черновики постов»): список — дата, вид, кратко, статус; отборы по виду и статусу.
- Карточка: картинка, текст (можно поправить перед копированием), «Скопировать текст», «Скачать картинку», «Опубликовал» / «Отклонить».

### Настройки
- Включить/выключить каждый вид, расписание, шаблоны текстов, минимальное число посылок для показа страны, период для сроков.
- Галочка «публиковать без проверки» — завести сразу, выключена; работать начнёт в шаге 2.

## Безопасность данных — обязательно
- Только общие цифры. **Никаких** имён, кодов клиентов, адресов, телефонов, треков, номеров посылок.
- Страну показывать, только если посылок в неё за период не меньше порога из настроек (на старте 5); меньше — в «другие страны». Так никого нельзя узнать.
- Сроки — только по доставленным посылкам; мало данных (меньше порога) — страну не показывать.

## Границы
- Не трогать текущую работу чатов «админка», «кабинет клиента», «выкуп». В общих файлах меню — только добавить пункт.
- Без подключения к Facebook / Instagram / Telegram — это шаг 2.
- Без видео (TikTok, YouTube) — позже.

## Шаг 2 (не делать сейчас, для понимания)
Подключение соцсетей с сервера (без VPN у владельца): Facebook + Instagram через Meta, Telegram-канал через бота. Кнопка «Опубликовать», а при включённой галочке — публикация по расписанию.

## Как сдать
- Один-два PR. Короткая инструкция `docs/product/инструкция-контент.md`.
- Проверить на рабочей базе: собрать итоги прошлой недели и сроки за 90 дней, убедиться, что в тексте и картинке нет личных данных и стран с 1–2 посылками.
