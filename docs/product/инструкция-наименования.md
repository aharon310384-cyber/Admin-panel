# Наименования товаров: группы и товары

Коротко для администратора. Где: **Склад → Наименования товаров**.

## Как устроено
Как справочник «Номенклатура» в 1С: **группы** (папки) и **товары** внутри них. Решение владельца 2026-10-26: прежние «разделы» («Сумки, обувь, аксессуары», «Одежда»…) стали группами.

- **Группа** — только для порядка в справочнике. В заказе её выбрать нельзя, ИИ её не видит, HS-кода у неё нет. В группе могут лежать и товары, и другие группы.
- **Товар** — то, что выбирается в заказе. У товара есть HS-код для таможни ЕС.
- Группа или товар — задаётся при создании и потом не меняется.

## Список
Открыта одна группа: сверху её группы (папки), под ними товары. Над таблицей — путь: «Все группы › Сумки, обувь, аксессуары». Щелчок по названию группы или двойной щелчок по строке открывает группу, карандаш рядом — карточку группы. Двойной щелчок по товару открывает его карточку.

Поиск ищет по всем группам сразу: по коду, наименованию, названию группы и HS-коду. Под найденной записью видно, в какой она группе. «Сбросить поиск» возвращает к списку групп.

## Создать, перенести, удалить
- **«Создать»** — новый товар, **«Создать группу»** — новая группа. Обе ложатся в группу, которая сейчас открыта, — её можно сменить в поле «В группе».
- **Перенести** товар или группу — выбрать другую группу в поле «В группе» карточки. Группу нельзя положить в саму себя или в свою подгруппу.
- **Удалить группу** можно только пустую: сначала перенесите или удалите то, что в ней лежит.
- Сменили HS-код товара — официальное описание кода ЕС у него очищается (оно было к прежнему коду).

## Заказы
В поле «Наименование» заказа подсказываются только товары. Если название совпало с товаром полностью, в заказ записываются товар, его группа и HS-код — снимком на момент сохранения. Потом поменяете справочник — уже сохранённые заказы не изменятся.

Загрузка из Excel справочник не использует (решение владельца): наименование берётся как в ячейке.

## Обновление базы
При деплое `npm run db:upgrade` сам запускает `db:upgrade:product-names`. Один раз, пока групп ещё нет, он отмечает группами разделы (записи, в которых лежат товары). Записи из удалённых разделов он поднимает на верхний уровень. Повторный запуск ничего не меняет.

## Ещё не решено
Владелец отвечает по одному вопросу:
1. Состав: 360 товаров подобрал ИИ — оставить и править или собрать список из настоящих названий в заказах.
2. Синонимы, как у стран («Сумка», «сумочка», «bag» — один товар).
3. Код — присваивать автоматически и без `PF-`.
4. Наименования EN/CN и описание кода ЕС — пока нигде не используются.

Менять справочник может только администратор, менеджер видит список.
