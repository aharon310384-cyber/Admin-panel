# Курс: где задаётся и где видна история

Коротко для администратора. Где: **Финансы → Курс**.

## Где задаётся
- **Курс ¥ за $** — по нему считаются новые посылки и переводятся юани в доллары при вводе заказов.
- **Курс ¥ за €** — для таможенной пошлины ЕС.

Других курсов в программе нет. Не задан курс — оформление посылки, массовый ввод заказов и загрузка строки из Excel остановятся с сообщением «Не задан курс… — задайте его в «Финансы → Курс»». Из Excel берётся курс строки, если он в ней есть.

У посылки курс запоминается при расчёте: смена курса не пересчитывает уже созданные посылки.

## История изменений
Внизу страницы — **История изменений курса**: когда, какой курс, было → стало, кто поменял. Новые записи сверху. Запись появляется только когда курс действительно изменился; сохранение без изменений её не добавляет. Первая запись — «курс на момент запуска журнала»: каким был курс, когда журнал появился, и кто его тогда поставил.

Менять курс может только администратор, менеджер видит курс и историю.
