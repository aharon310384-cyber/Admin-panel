# Задание: всё о компании — из кода в настройки

Для рабочего чата «админка». Решение владельца 2026-10-18, владелец разрешил начинать.
Зачем: систему будут продавать другим складам и сервисам, админка станет админкой ShuTai, кабинет клиента остаётся PostmanFox. Подробно — `docs/product/будущее.md`, разделы 0, 6, 7.

## Правило
В коде не остаётся ничего о конкретной компании. Название, логотип, цвета, контакты, адреса сайтов, тарифы, курсы, комиссии, услуги, тексты сообщений — в настройках или справочниках в базе, меняются из админки.

## Что нашлось при беглом просмотре (2026-10-18, не полный список)
- **Название и адреса PostmanFox прямо в коде — 18 файлов:** `actions/parcel-form.ts`, `app/(admin)/dashboard/page.tsx`, `app/(admin)/finance/finance-form.tsx`, `app/(admin)/tariffs/page.tsx`, `app/api/telegram/webhook/route.ts`, `app/cabinet/layout.tsx`, `app/cabinet/page.tsx`, `app/cabinet/tariffs/page.tsx`, `app/entrance/layout.tsx`, `app/entrance/page.tsx`, `app/login/page.tsx`, `components/cabinet/cabinet-sidebar.tsx`, `components/cabinet/track-number.tsx`, `components/layout/topnav.tsx`, `components/orders/order-bulk-import.tsx`, `lib/ai-order-parser.ts`, `lib/geo-validation.ts`, `lib/postmanfox-tariffs.ts`. Логотип — `public/brand/`.
- **Тарифы в коде:** `lib/postmanfox-tariffs.ts` (цены, сроки, доп. услуги, ссылка на сайт) — им пользуются страницы тарифов в админке и кабинете и массовый ввод заказов. При этом в базе уже есть `ShippingTariff` и `ServiceTariff` — тарифы живут в двух местах.
- **Курс в коде:** `lib/ai-order-parser.ts` — `CNY_PER_USD = 7.1`, хотя курс уже есть в `FinanceSettings`.

## Курс: в коде 7,1, а настоящий — 6,8 (владелец, 2026-10-18)
Курс задаётся в «Финансы → Курс» (`FinanceSettings.exchangeRateCnyPerUsd`). Расчёт посылки, карточка, оплаты, экспорт и пошлина ЕС берут его оттуда — это правильно. Но число 7,1 вписано ещё в нескольких местах:
- **`lib/ai-order-parser.ts`** — `CNY_PER_USD = 7.1`: при массовом вводе заказов цена в юанях переводится в доллары по 7,1, а не по курсу из настроек. **Это ошибка в деньгах — исправить первой.**
- `components/orders/order-bulk-import.tsx` — подсказка «≈ … ¥ по курсу 7.1»: показывать курс из настроек.
- `actions/parcel-form.ts` — запасное значение `?? 7.1`, если настроек нет.
- `prisma/schema.prisma` — `@default(7.1)` у `FinanceSettings` и у оплаты; `prisma/seed-v2.js`, `prisma/seed.ts` — 7,1 для новой базы.
Цель: курс берётся только из настроек; запасного числа в коде нет (если курс не задан — просить задать его, а не считать по выдуманному). Проверить, что в настройках рабочей базы стоит 6,8.

## Как задумано (предложение, детали решает рабочий чат)
1. Настройки компании в базе: название, логотип, цвета, контакты, сайт, ссылка для отслеживания, подпись в Telegram. Раздел «Администрирование → Компания».
2. Два бренда сразу: админка (склад) — ShuTai, кабинет клиента и Telegram — PostmanFox. Бренд кабинета — у компании-владельца клиента.
3. Тарифы и услуги — только из справочников в базе; `lib/postmanfox-tariffs.ts` перенести в начальные данные (seed) и убрать из страниц.
4. Курс — только из `FinanceSettings`.
5. Новые таблицы — с полем «компания» (для PostmanFox, ShuTai и будущих клиентов системы). Для старых таблиц — отдельно обсудить, когда дойдём до нескольких компаний.
6. После переделки поиск по слову «PostmanFox» в коде ничего не находит (кроме начальных данных).
