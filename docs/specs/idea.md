# ИДЕЯ: Полнофункциональная Админ-панель для интернет-магазина

## Концепция

Превратить текущий шаблон в **готовую систему управления интернет-магазином** для малого и среднего бизнеса. Акцент — простота, скорость и удобство для менеджеров без технических знаний.

---

## Целевая аудитория

- Владельцы небольших интернет-магазинов
- Менеджеры по работе с заказами
- Администраторы каталога товаров

---

## Ключевые модули

### 1. Авторизация и роли
- Вход по email + пароль (NextAuth.js)
- Две роли: **Администратор** (полный доступ) и **Менеджер** (только заказы и клиенты)
- Защищённые роуты через middleware

### 2. Управление заказами
- Список заказов с фильтрацией по статусу, дате, сумме
- Детальная страница заказа с историей изменений статуса
- Смена статуса одним кликом (NEW → PROCESSING → SHIPPED → COMPLETED)
- Экспорт в CSV/Excel

### 3. Управление клиентами
- Список клиентов с поиском по имени, email, городу
- Карточка клиента: история заказов, сумма покупок, дата регистрации
- Возможность заблокировать клиента (soft delete)

### 4. Каталог товаров
- CRUD для товаров: создание, редактирование, архивация
- Загрузка изображений (хранение в S3 или локально)
- Управление остатками (stock)
- Быстрое включение/отключение товара (isActive)

### 5. Аналитика на Dashboard
- Реальные данные вместо mock: выручка, заказы, новые клиенты
- Графики за неделю/месяц (recharts или Chart.js)
- Топ-5 товаров по продажам
- Последние 10 заказов

---

## Техническая реализация

| Задача | Решение |
|--------|---------|
| Авторизация | NextAuth.js с Prisma Adapter |
| Формы | React Hook Form + Zod валидация |
| Таблицы | TanStack Table (фильтры, сортировка, пагинация) |
| Графики | Recharts |
| Загрузка файлов | next/server + локальная папка /uploads или AWS S3 |
| Уведомления | Toast-нотификации (sonner) |
| Состояние | Server Actions (Next.js 15) без Redux |

## Новые роуты

```
/login                    — страница входа
/dashboard                — главная с реальной аналитикой
/orders                   — список заказов
/orders/[id]              — детальная страница заказа
/customers                — список клиентов
/customers/[id]           — карточка клиента
/products                 — каталог товаров
/products/new             — создание товара
/products/[id]/edit       — редактирование товара
/settings                 — настройки аккаунта
/api/orders               — REST API для заказов
/api/customers            — REST API для клиентов
/api/products             — REST API для товаров
/api/upload               — загрузка изображений
```

---

## Что даёт проект (ценность)

1. **Экономия времени** — менеджер обрабатывает заказы в 3 клика
2. **Прозрачность** — вся история изменений сохраняется
3. **Безопасность** — soft delete, ролевой доступ, авторизация
4. **Масштабируемость** — архитектура готова к росту нагрузки
