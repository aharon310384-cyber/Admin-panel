## Исходная формулировка пользователя

> Переименовать кнопки, обработчик, получатели. Убрать кнопки «Редактировать». Переместить столбцы местами. Создать клиентскую панель и оставить эту панель для клиентов, для админки создать новую (у клиента должно быть самое лучшее и красивое, подключить дизайнера). Создать вкладку «Справочники», где первый во вкладке «Клиенты», «Наименования» и т. д. Этот справочник закрыть для клиентов. Создать Swagger или Redoc и всё сохранить внутри документа. Залить в GitHub. Залить в Docker. Готовить к релизу — только подготовка. После исправления для клиентов начинать создавать аккаунты для клиентов, развернуть Docker.

## Открытые вопросы

1. **Переименования.** Что именно переименовать и в какие новые названия? Конкретные пары `было → стало` для:
   - кнопок (где конкретно?),
   - раздела «Обработчик» (это страница `/orders` или что-то ещё?),
   - раздела «Получатели» (это `/recipients`?).
2. **«Редактировать».** В каких таблицах убрать кнопку (`/orders`, `/parcels`, `/recipients`, везде)? И вместо неё что — клик по строке открывает редактирование, или редактирование вовсе закрыто?
3. **Перестановка столбцов.** В какой именно таблице и какой новый порядок?
4. **Клиентская/админская панель.** Сейчас вся админка живёт в `app/(admin)/` под одной ролью. Как разводим:
   - (a) текущая `(admin)` → переименовать в `(client)` (это для клиентов), а админу — новый layout `(admin)` с минимально нужным UI;
   - (b) текущая остаётся `(admin)`, а клиенту делаем отдельный путь, например `/cabinet/`;
   - (c) другой вариант?
5. **Справочники.** Полный список вложенных страниц? Сейчас точно есть «Клиенты», «Наименования». Ещё могут быть «Страны», «Типы доставки», «Услуги», «Статусы», «Тарифы». Что из этого нужно?
6. **GitHub.** Создать новый репозиторий (имя, public/private)? Или есть уже существующий? Сейчас в проекте есть локальный git, но remote не настроен.
7. **Docker registry.** Куда заливать образ — Docker Hub, GitHub Container Registry, что-то другое?
8. **Аккаунты клиентов.** Как создаются:
   - менеджер создаёт вручную и отправляет логин/пароль клиенту,
   - менеджер высылает приглашение по email со ссылкой на регистрацию,
   - клиент сам регистрируется на публичной странице?
9. **Хостинг.** Где разворачивать Docker — VPS (какой?), Vercel (Docker не нужен), Railway, Render, своя инфраструктура?
10. **Дизайн.** Привлекать `ui-designer` через Google Stitch — какие референсы? Какой бренд-стиль (PostmanFox: glassmorphism, OKLCh, Space Grotesk + Inter — взять текущий или переделывать)?

## Решения (ответы пользователя)

- **Панели:** оставляем `(admin)` как админку; клиенту — **отдельный путь `/cabinet`** (новый layout, красивый UI, минимум функций: мои заказы, оформить, мои посылки, профиль).
- **Справочники:** в одной вкладке — Клиенты, Наименования, Страны, Типы доставки, Статусы, Услуги.
- **Редактирование:** клик по строке таблицы открывает карточку. Кнопка «Редактировать» в последнем столбце убирается.
- **Переименования:** ожидаем конкретные пары «было → стало» от пользователя.
